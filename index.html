How to play

  1. Press and drag across adjacent letters (diagonals ok) to form a word.
  2. Release to submit. If valid, tiles are removed and colors count toward goals.
  3. Words of 4/5/6/7+ grant boosters: Breaker / Row / Column / Rainbow.
  4. Use a booster by tapping its tile, then tap a target.
Boosters (actualizados):
  • 4 letras → 🔨 Block breaker: toca el booster y luego una ficha para romper solo esa pieza.
  • 5 letras → ➡️ Row breaker: toca el booster y luego una ficha para romper toda la fila.
  • 6 letras → ⬇️ Column breaker: toca el booster y luego una ficha para romper toda la columna.
  • 7+ letras → 🌈 Rainbow (comodín): úsalo dentro de una palabra; puede reemplazar cualquier letra/color.
